# Food Delivery Application

A React-based food delivery application with reusable UI components, centralized cart state management, and REST API integration.

## Features

* Browse available meals
* Add, update, and remove cart items
* Centralized cart state using Context API and useReducer
* Checkout workflow
* Reusable components for meals, cart, and checkout
* Custom HTTP hook for API requests
* Loading and error state handling

## Tech Stack

**Frontend:** React.js, Context API, useReducer, Custom Hooks, CSS
**Backend:** REST APIs

## Getting Started

```bash
git clone https://github.com/Food-Delievery
cd Food-Delievery
npm install
npm run dev
```
